# Super Dash Maker Menu

If you've ever played Mario Maker 2, you might find the UI to be a lot different to one like Geometry Dash.
This mod changes Geometry Dash's menu to be like Mario Maker 2!

This is probably the closest they'll be to eachother because if I changed Mario Maker's menu to be like Geometry Dash, Nintendo would not be very happy with me, would they?
